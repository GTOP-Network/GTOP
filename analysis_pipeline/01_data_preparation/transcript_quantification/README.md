# Short-read RNA-seq transcript quantification and transcript usage phenotypes

Transcript expression was quantified using **Salmon (v1.10.0)** and **RSEM (v1.3.3)** against the enhanced transcript reference combining GTOP novel transcripts and GENCODE v47 annotations. RSEM used alignments generated by **STAR (v2.7.3a)**. Transcripts with highly concordant estimates between the two methods were retained, and their estimates were averaged to obtain the expression values used in downstream analyses.

For comparison, Salmon quantification was also performed using the GENCODE v47 reference alone.

---

```bash
cd scripts
```

## 1. Transcript quantification using Salmon

### 1.1 Prepare reference indices

```bash
python salmon_run.py prepare
```

### 1.2 Quantify individual samples

```bash
python salmon_run.py run
```

### 1.3 Combine sample results

```bash
python salmon_run.py combine
```

## 2. Transcript quantification using RSEM

### 2.1 Prepare reference files

```bash
python rsem_run.py prepare
```

### 2.2 Quantify individual samples

```bash
python rsem_run.py run
```

### 2.3 Combine sample results

```bash
python rsem_run.py combine
```

## 3. Integrate Salmon and RSEM estimates

Transcripts with highly concordant quantification results across the two methods were selected. For each retained transcript, the Salmon and RSEM estimates were averaged within each sample to generate the expression matrix for downstream analyses.

```bash
Rscript salmon_rsem_average_quantification.R
```

## 4. Construct transcript usage phenotypes

Transcript usage was calculated from the averaged expression estimates as the proportion of each transcript's expression relative to the total expression of its parent gene. Tissue-specific filtering, missing-value imputation, and normalization were then applied to generate phenotypes for downstream QTL analysis.

```bash
python make_molecular_phenotypes.py
```
