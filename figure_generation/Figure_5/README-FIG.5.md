# Figure 5 generation
***
This directory contains the scripts for generating Figure 5:
* Figure 5A: Histogram shows the R² correlation of SV-eQTL (left) or TR-eQTL (right) and their best-tagging SNV genotypes in individual tissues; SVs or TRs poorly tagged (R² < 0.8) are highlighted.
* Figure 5B: Number of fine-mapped variants in 95% credible sets (CSs), stratified by variant type: SNV, TR, and SV.
* Figure 5C: Number of credible sets (CSs) across GTOP tissues (top), and proportion of CSs with or without SV/TR, and with SV/TR as the lead variant, based on joint fine-mapping (bottom).
* Figure 5D: Overall number of fine-mapped eQTL credible sets containing SV, TR, or only SNV, with CSs having SV or TR as lead highlighted in orange.
* Figure 5E: Enrichment of SV or TR as fine-mapped causal variants in credible sets selected with gradient PIP scores (0 to 0.8).
