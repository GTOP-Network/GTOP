# Figure 4 generation
***
This directory contains the scripts for generating Figure 4:
* Figure 4A: Distribution of the size of 95% credible sets (CSs) and comparisons between the cross-ancestry fine-mapping (GTEx + GTOP) and single-population fine-mapping (GTOP and GTEx).
* Figure 4B: Proportion of CSs with best (maximum) PIP greater than 0.8 across all 95% CSs in each analysis.
* Figure 4C: The distribution of PIP for all variants in the fine-mapped CSs associated with eGene SAMD9L in the whole blood.
* Figure 4D: Geographic frequencies of GTOP independent eQTLs across four continental groups, with MAF < 1% in at least one group.
* Figure 4E: LocusZoom plots (top) and gene structure diagram (bottom) showing colocalization between urticaria signal and pb-QTLs.
* Figure 4F: Scatter plot of allele frequencies (AF) in gnomAD EAS versus GTEx EUR population, with variants colored based on frequency differentiation.
